# Koch Snowflake

<img src="https://dkwise.wordpress.com/wp-content/uploads/2018/05/triangles.jpg" width="250" align="left" style="margin-right: 20px;">

Built this because I wanted to zoom into a fractal forever and actually see it stay a fractal, not just get blurry. Go backend recomputes the Koch snowflake geometry live based on how deep you're zoomed, frontend tiles copies of it edge to edge so panning never hits empty space. Threw in some glow and color drift because a snowflake fractal deserves to look unhinged, not like a math textbook diagram.
